# Чистильщик папок

Простое и лёгкое приложение для Windows, которое помогает быстро навести порядок в любой папке на компьютере.

## Скачать и установить

👉 **[Скачать последнюю версию (`FolderCleaner_Setup.exe`)](https://github.com/worldruschel/folder-cleaner/releases/latest)**

- Подходит для **Windows 10 / 11 (64-bit)**, дополнительных программ и библиотек устанавливать не нужно.
- При установке создаётся ярлык на рабочем столе и в меню «Пуск».
- **Автообновление**: приложение само проверяет выход новых версий и предлагает обновиться в один клик.

## Что умеет приложение

Выберите любую папку (или воспользуйтесь быстрым выбором: *Загрузки*, *Рабочий стол*, *Документы*, *Temp*) и нажмите **«Старт»**. Программа найдёт:

- **Временные файлы и кэш** (`.tmp`, `.bak`, `.old`, `Thumbs.db`, папки кэша и т.п.)
- **Точные дубликаты файлов** (оригинал сохраняется, копии предлагаются к удалению)
- **Пустые файлы и пустые папки**
- **Файлы журналов (`.log`) и старые установщики** (`.msi`, `.iso`, установочные `.exe`)
- **Крупные файлы от 50 МБ** — отмечаются отдельно как «На проверку», чтобы вы случайно не удалили нужное

Для каждого пункта можно открыть расположение в Проводнике или удалить его отдельно, либо очистить всё сразу кнопкой **«Очистить всё»**.

> **Безопасность:** все удаляемые файлы и папки перемещаются в **Корзину Windows** — при необходимости их всегда можно восстановить.
