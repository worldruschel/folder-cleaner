# Чистильщик папок (FolderCleaner)

Простое и лёгкое Windows-приложение для анализа выбранной папки и безопасной очистки ненужных файлов.

## Возможности
- **Установка через мастер установки** (`FolderCleaner_Setup.exe`) с автоматическим добавлением ярлыка на рабочий стол и в меню «Пуск».
- **Автоматическое обновление через GitHub Releases**: при запуске (и по кнопке обновления в шапке) приложение проверяет свежую версию в репозитории `worldruschel/folder-cleaner`, скачивает установщик и обновляется в один клик.
- **Выбор любой папки** + быстрый выбор стандартных папок (`Загрузки`, `Рабочий стол`, `Документы`, `Temp`).
- **Анализ по кнопке «Старт»**:
  - Временные файлы и папки кэша (`.tmp`, `.bak`, `.old`, `Thumbs.db`, `__pycache__`, `.cache` и др.)
  - Точные дубликаты файлов (проверка по размеру и SHA-256)
  - Пустые файлы (0 Б) и пустые папки
  - Файлы журналов (`.log`)
  - Установщики (`.msi`, `.iso`, установочные `.exe`)
  - Крупные файлы от 50 МБ (отмечаются как «На проверку»)
- **Удобное управление**:
  - Кнопка **«Удалить»** и кнопка открытия в Проводнике напротив каждого пункта
  - Кнопка **«Очистить всё»** для пакетной очистки
  - Фильтры по категориям и подсчёт освобождённого места
- **Безопасность**: все удаляемые файлы перемещаются в Корзину Windows — их всегда можно восстановить.

## Сборка локально
```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Version 1.0.0
```
Готовый установщик появится в `dist\FolderCleaner_Setup.exe`.

## Выпуск новой версии (автообновление)
После внесения изменений достаточно запушить тег вида `v1.0.1`:
```powershell
git tag v1.0.1
git push origin v1.0.1
```
GitHub Actions автоматически соберёт `FolderCleaner_Setup.exe` и опубликует релиз — все установленные копии приложения увидят обновление и предложат обновиться.
